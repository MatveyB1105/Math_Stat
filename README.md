# 📊 Математическая статистика (Math_Stat)

Репозиторий содержит материалы и практические реализации лабораторных работ по курсу **«Математическая статистика»**. 

В проекте демонстрируется применение классических статистических методов для проверки гипотез, анализа распределений и работы с выборками с использованием языка Python и специализированных библиотек для анализа данных.

## 📝 Описание
Каждая лабораторная работа оформлена в виде интерактивного Jupyter Notebook (`.ipynb`), который включает:
- Формулировку задачи и математическое описание методов.
- Генерацию или загрузку исходных данных.
- Реализацию статистических критериев (как с использованием готовых библиотечных функций, так и "с нуля" для глубокого понимания алгоритмов).
- Визуализацию результатов (гистограммы, эмпирические функции распределения, графики сравнения).
- Интерпретацию полученных p-value и статистических выводов.

## 💻 Технологический стек
- **Язык**: Python 3.x
- **Среда выполнения**: Jupyter Notebook
- **Основные библиотеки**:
  - `NumPy` – векторные вычисления и работа с массивами данных.
  - `Pandas` – структурирование и предобработка табличных данных.
  - `SciPy` (`scipy.stats`) – реализация статистических тестов и функций распределений.
  - `Statsmodels` – расширенные статистические модели и тесты (например, `ztest`, `sign_test`, `ECDF`).
  - `Matplotlib` & `Seaborn` – визуализация данных и статистических графиков.
